# Castaway Colony — playtest quests (editor and development builds only).
# Shown on the HUD tracker and on Esc > Information > DEV. Newest batch first.
#
#   ## yyyy-mm-dd Feature          a batch: one recent change to test
#   - @signal Short quest text     ticks itself (done + PASS) when the game raises that signal
#   - Short quest text             the tester ticks it after checking
#
# Keep a quest under ~70 characters — it is one line on the panel. A signal is
# the proof, so a quest only stays manual when nothing in code can see it (a
# look, a feel, a "nothing bad happened over time"). Signals come from
# DevQuests.Signal(...) at the point of effect; the set in use:
#   research:<id>  craft:<id>  build:<buildingtype>  specialist:<trade>
#   specialist:idle  specialist:locked  warrior  archer  warrior:6  rearm  picker
#   recruit:no_idle  recruit:housing_full  hungry  starving  colonist_left
#   raid  raid_survived  victory  escape  defeat  continue  continue:escape
#   deposit  campfire  info  info:<tab>  info:dev  tracker  report  auto  persisted
#   priority  priority:forage_back  priority:craft_wins  worker_click  worker_click:busy
#   craft_by_colonist  craft_by_player  craft:specialist_holds  hud:food
#   stance:<defensive|offensive|follow>  stance_key:follow  combat_box:<shown|hidden|stance>
#   formation:<line|wedge|ring|loose|auto>  formation:auto_line  collapse  collapse:restored
#   rebind:militia  engage:<follow|offensive>  intercept:advance  kite:<offensive|hold>
#   attack_slots:3  patrol:archer  patrol:spread  arrow_hit  knockout  knockout:follow
#   dawn:held  dawn:released  dawn:quiet  garrison
#   gearup  gearup:job  gearup:idle  gearup:delivered  gearup:after_flee
#   stroll  stroll:home  stroll:interrupted  stroll:campfire_only
#   crowd:split  dropoff:spread  forage:shed  pickup:unreachable  shed:stone  pickup:player:stone
#   fog:node_revealed  fog:raider_revealed  reveal:<on|off>  cheat:stock_full
#   fog:node_skipped  fog:raider_unseen  fog:ghost  fog:wall  minimap:click  minimap:landing
#   sky:<sunny|slightly|partly|cloudy|off>  graphics:<preset|custom>
#   faction:bootstrap  faction:rival  faction:<hostile|neutral|allied>
# crowd:split, dropoff:spread and patrol:spread are STATE checks polled by the
# tracker twice a second while their quest is open; everything else is an event.
# A finished batch is deleted from here once its report is in; it stays in the
# changelog and the phase history.
